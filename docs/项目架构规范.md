

### 常用命名规范

```
1.大驼峰命名法，如：UserName
2.小驼峰命名法，如：userName 
3.URL格式命名法，如：user_name 
```

### 数据库设计规范

```
1.数据库整体命名采用URL格式命名法；
2.数据库编码统一采用utf8mb4，排序规则utf8mb4_general_ci；
3.数据表设计时，不采用外键关联；
4.数据表主键统一采用bigint类型,并使用雪花算法生成ID，纪元日期为2020-11-18(公司成立日期)；
5.数据表除主键外其他字段均可为空，但是需要设置默认值（除特殊日期类型外）；
6.枚举类型字段，统一采用tinyint类型，并在注释栏列出枚举值（在代码中定义相应的枚举类型）；
7.日期类型字段统一采用datetime类型，部分特殊情况适当采用date类型和time类型；
8.公有字段：create_time,update_time,is_del，通常情况下都需要，特殊情况可部分省略（如关系表等）
`create_time` datetime(0) NULL DEFAULT CURRENT_TIMESTAMP(0) COMMENT '创建时间',
`update_time` datetime(0) NULL DEFAULT CURRENT_TIMESTAMP(0) ON UPDATE CURRENT_TIMESTAMP(0) COMMENT '更新时间',
`is_del` tinyint(1) NULL DEFAULT 0 COMMENT '是否删除',
```

### 接口命名规范

```
# http://www.ruanyifeng.com/blog/2014/05/restful_api.html
统一采用RESTful风格命名规范，在REST中的一切都被认为是一种资源，每个资源由URI标识，URI中只能使用[a-z_-],尽量不使用动词。
HTTP谓词：
GET（SELECT）：从服务器取出资源（一项或多项）。
POST（CREATE）：在服务器新建一个资源。
PUT（UPDATE）：在服务器更新资源（客户端提供改变后的完整资源）。
PATCH（UPDATE）：在服务器更新资源（客户端提供改变的属性）。
DELETE（DELETE）：从服务器删除资源。

实例：
GET /user：列出所有用户
GET /user/page：用户分页列表
GET /user/{user_id}：获取用户详情
POST /user：新建用户
PUT /user/{user_id}：更新某个指定用户的信息(客户端提供全部用户信息)
PATCH /user/{user_id}：更新某个指定用户的信息(客户端提供部分用户信息)
DELETE /user/{user_id}：删除某个用户

# 下级资源
GET /user/{user_id}/address：列出某个指定用户的所有地址
DELETE /user/{user_id}/address/{address_id}：删除某个指定用户的指定地址

```

### 状态码说明

| 状态码 | 状态码描述                                                   |
| ------ | ------------------------------------------------------------ |
| 200    | 操作成功                                                     |
| 400    | 业务异常，如：缺少必要的请求参数，参数校验失败，自定义业务消息等 |
| 401    | 请求未授权                                                   |
| 403    | 请求被拒绝                                                   |
| 404    | 没找到相关资源                                               |
| 405    | 不支持当前请求方法                                           |
| 415    | 不支持当前媒体类型                                           |
| 500    | 服务器异常                                                   |
| 501    | 服务调用异常                                                 |
| ...    | 其他业务异常状态码                                           |
